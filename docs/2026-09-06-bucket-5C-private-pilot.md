## Scope and gate

First bot: Webtechnosys AI Agency, BusinessGPT. Website/standalone conversation, approved knowledge, consented enquiry capture and human handover only. WhatsApp, payments and external booking writes excluded. Sharing the approved training-booking link is permitted; claiming a confirmed booking is not.

Before the human run, Operations must record current tenant knowledge readiness (80% of the specified ten-topic bank; identity/contact/training-booking/safety/handover mandatory), freshness, unresolved conflicts/flags, unsigned claims, installation and pause/handover availability. No earlier platform test score substitutes for these gates. The existing generic BusinessGPT coverage calculation is not automatically the bespoke ten-topic bank.

Do not change public access, pause the existing bot, or send invitations automatically under this plan. Agree the private testing window with the owner. A public standalone URL is not access-controlled merely because testers call it private.
