# AiFrogi Platform Flow Memory From Video Review

## Purpose

The video gives a useful reference for the full shape of a WhatsApp SaaS platform: public marketing, signup, guided onboarding, WhatsApp API application, embedded training, inbox/live chat, contacts, campaigns, ads, flows, developer tools, and account plan/billing surfaces.

This memory is not a direction to copy AiSensy visually. It is a direction to understand the platform journey and then build a cleaner, more premium AiFrogi version.

## Observed Flow

1. Public marketing site builds trust first.
   - Clear WhatsApp marketing positioning.
   - Trust signals include Meta Business Partner, brand logos, video explainer, pricing, integrations, footer resources, and contact/support numbers.
   - CTA language is direct: start free, login, pricing, book demo, partner/resources.

2. Signup is business-context heavy.
   - User starts free plan.
   - Signup captures email/password or Google login.
   - Business form asks company name, description, country, state, company size, industry, website URL, phone, and timezone.
   - The business website is treated as a prerequisite for WhatsApp API approval.

3. App home is onboarding-first for new accounts.
   - Account name is visible at top.
   - Top status shows WhatsApp Business API status, for example pending, with an Apply Now CTA.
   - Current plan is visible, with Explore Plans.
   - Main card is a guided step: Apply for WhatsApp Business API.
   - Requirements are expressed simply: registered business and working website.
   - Embedded video explains the current step.
   - Primary action is Continue with Facebook.

4. Right-side dashboard assists setup and monetization.
   - Wallet/balance is shown.
   - Buy More is available.
   - Cards promote tools such as Customize WhatsApp Link and WhatsApp Website Button.
   - Trial/premium upsell is visible without blocking the onboarding flow.

5. Meta/Facebook onboarding is still required, but guided.
   - Flow moves into Meta embedded signup style screens.
   - It creates/selects WhatsApp business profile and business account details.
   - Fields include WhatsApp business account name, display name, and category.
   - The SaaS platform frames this as “apply/get WhatsApp API,” not as raw Meta credential management.

6. Email reinforces onboarding.
   - A welcome email includes a quick start checklist:
     - Apply for WhatsApp Business API.
     - Connect business number and complete verification.
     - Get first template approved and send a test campaign.
   - Email CTAs include Apply for WhatsApp API, Schedule a Call Now, and Watch a short walkthrough.

7. Main app modules visible in side navigation.
   - Dashboard
   - Live Chat
   - History
   - Contacts
   - Campaigns
   - Ads Manager
   - Flows
   - Developer
   - All Projects

8. Flow builder is a key product surface.
   - Visual canvas with a phone-like node preview.
   - Message types include text buttons, media buttons, list, catalogue message, single product, multi product, and template.
   - Actions are grouped separately.
   - Builder includes AI prompt bar: “What should AI create?”
   - CTA: Generate flow with AI.
   - Controls include Fallback & Intents, Active/Inactive toggle, and Save Changes.

## Product Lessons For AiFrogi

1. AiFrogi should be onboarding-led before it is dashboard-led.
   - For a new client, the first screen should answer: what is complete, what is waiting, and what action is required.
   - Once live, the first screen can become operations-led: inbox, reply queue, campaigns, automation, health.

2. External prerequisites must be translated into simple client language.
   - Instead of “Meta app/token/webhook,” say:
     - Business verified
     - Website ready
     - WhatsApp number connected
     - Facebook connection complete
     - Template approved
     - Messaging live

3. Embedded education is important.
   - Each critical setup step should include one short video/help card or guided explanation.
   - The user should never need to search docs during onboarding.

4. The Setup screen should become a concierge.
   - Current AiFrogi Setup/Onboarding should show:
     - WhatsApp API status
     - Meta status
     - Billing/wallet status
     - Template approval status
     - Webhook health
     - Test message status
     - Support escalation

5. Campaigns need a guided wizard.
   - Recommended campaign flow:
     - Pick audience
     - Select approved template
     - Preview WhatsApp message
     - Send test
     - Confirm compliance
     - Send batch
     - Track delivery/read/replies

6. Flows/Automation should be a premium differentiator.
   - AiFrogi should eventually include a visual automation builder.
   - For early version, use a guided template library:
     - AI audit intake
     - 30-day trial intake
     - Missed reply follow-up
     - Human handoff
     - Lead qualification
     - Appointment/callback booking

7. Super Admin must mirror the customer journey.
   - Team should see each client’s current onboarding stage, WhatsApp status, billing status, templates, tickets, and last activity.
   - Support should know exactly what is blocking the client without asking for Meta screenshots repeatedly.

8. Pricing and plan clarity matter.
   - The platform should always show current plan, credits/balance, and upgrade path.
   - Billing should be simple: platform subscription plus WhatsApp/Meta usage explanation.

## Design Direction

Use the approved AiFrogi app design, not the green reference design:
- White surface
- Plum text
- Magenta primary action
- Soft multi-color status signals
- Calm typography
- Compact business app layout
- Clear next action on every screen

AiFrogi should feel more premium and less noisy than the reference platform: fewer distractions, clearer status, better predictive guidance, and stronger human-support confidence.
